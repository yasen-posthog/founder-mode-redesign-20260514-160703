Frequently Asked Questions

Is there a mobile app?
Currently, Scaffold Task Manager is optimized for desktop web browsers. Mobile responsiveness is a feature we may consider in the future, but for now, we focus on providing the best experience on larger screens.
Do I need to create an account?
No, for v1, you access your task list via a unique magic link. This keeps things simple and gets you managing tasks faster without the friction of traditional logins.
Can I delete tasks?
In this initial version, tasks can be marked as complete but not deleted. Our focus is on tracking completion. We'll consider adding deletion based on user feedback.
What about due dates or reminders?
Scaffold Task Manager v1 prioritizes core task creation and completion. Features like due dates and reminders are deliberately excluded to maintain simplicity and will be evaluated for future updates.
